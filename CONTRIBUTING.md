# Contributing to BagsPay

1. Fork the repo and create a branch: `git checkout -b feature/my-change`.
2. Install and test: `npm install` then `npm test`.
3. Keep changes small and focused; add a test for new behaviour.
4. Never commit keys or `.env` files.
5. Open a pull request describing what changed and why.

Code style: plain ES modules, no build step, two-space indentation.
